## Post-close audit

После сообщения «закрыл» подтверждено отсутствие игры/сервера. Аудит работал только с файлами:

- **67/67** original records и **77/77** shadow records точно совпали с baseline.
- **22/22** неизменяемых файла установки совпали по хешам и metadata.
- Единственное ожидаемое изменение установленного набора — latch **SPENT**. Проверены точные
  before/after bytes через SHA-256, размер39, та же file identity, один link и mtime в пределах сессии;
  дополнительно сопоставлены probe/session/Y/intent/request/response/native log.
- Прежний post_close_v2 не ослаблялся: ему передана in-memory проекция после отдельной проверки
  latch. Полный сырой snapshot сохраняет реальный SPENT hash. Подтверждены точный rename прошлого
  игрового лога, штатные текущие логи и только timestamp у пустого chain_status; неизвестных изменений нет.
- Backup **27/27** повторно verified. Прежняя история **75 файлов** неизменна; полный журнал теперь112 файлов,
  отдельные read-only observation файлы сохранены дополнительно. Ничего не очищалось и не сбрасывалось.
- LOCAL **23 файла**, без добавлений/удалений; content изменился у7 файлов, metadata у8.
  Имена тестовых персонажа/мира сохранены, в журнале12 событий сохранения мира. Семантическая
  целостность saves и наличие NPC внутри них этим аудитом **не устанавливаются**. Restore не выполнялся.
- Итоговый game inventory246 файлов: добавлен только архив прежнего лога.
  SHA-256 snapshot: `120850afac7ff4242f5e07b32f8fa071607c2af411a06681cadf61e7bc56fe80`.
