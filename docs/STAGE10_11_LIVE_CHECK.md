## Разрешённая попытка — остановка до spawn

2026-11-18 пользователь разрешил один экспериментальный spawn. В той же сессии PID216444 повторно пройдены штатные проверки manifest/receipt/backup23/existing16 и LOCAL-контекста. Вызван один prepare (ground query), затем пять read-only status с интервалами 0.5s. Во всех ответах сохранялись GROUND, ok=true, attempted=false, пустая reason. READY не получен.

Локальный исполнитель завершился с `PROBE_NOT_READY_STOP`, не вызывая spawn. Это ограничение ожидания исполнителя (пять опросов), **не** доказательство отказа ground API и **не** истечение полного 20-секундного срока Lua. Причина незавершения callback в этом окне неизвестна. Последнее наблюдаемое состояние контроллера — GROUND, а не STOPPED; после остановки дополнительные игровые команды не отправлялись. Поздний callback сам по себе не создаёт NPC: отдельный spawn не отправлен.

Проверки файлов после остановки: 7/7 SHA-256 совпали с receipt, attempt.lock остался UNUSED, spawn-intent.json отсутствует, probe.json существует. Журналы и latch не сбрасывались. Приватные результаты prepare/status/error и after-stop-files.json сохранены в каталоге текущей сессии. Никаких изменений установленных модов, save edits, destroy или rollback не было. Полная post-close проверка ещё ожидает ручного закрытия игры. Unit-тесты не повторялись: изменены только отчёт и частный исполнитель диагностики.

Итог: `BLOCKED_BEFORE_SPAWN`, experimental_spawn_executed=false, spawn_ready=false, production_spawn_ready=false, render=UNKNOWN. Следующий шаг — ручное закрытие игры, post-close audit и разбор ground callback/ограничения ожидания. Повторный prepare/spawn и удаление probe journal автоматически запрещены.
