# Правила работы с проектом

- Общаться с пользователем по-русски.
- После каждой завершённой задачи обновлять `docs/PROGRESS.md` до итогового ответа: дата, выполненные изменения, результаты проверок, ограничения/блокеры и следующий шаг. Сохранять предыдущие записи; отличать план от выполненных действий. Вносить существенные итоги, сообщаемые пользователю.
- Перед продолжением работы читать `docs/PROGRESS.md`, чтобы учитывать текущее состояние проекта. Исторические проверки не выдавать за повторно выполненные.
- Не запускать игру, не устанавливать моды, не изменять файлы игры или сохранения без отдельного подтверждения пользователя. Подготовка документации не является таким подтверждением.
